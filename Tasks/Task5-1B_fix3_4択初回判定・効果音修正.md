# Task5-1B_fix3_4択初回判定・効果音修正

## 目的

4択クイズで初回回答時のみ発生する判定不具合と、
正解効果音が再生されない問題を修正する。

---

## 修正内容

### ① 初回回答時の不具合修正

現在、

4択クイズの最初の問題だけ、

- 正解でも
- 不正解でも

最初のクリックで選択肢だけが入れ替わる。

その後もう一度押すと正常に判定される。

これは正常ではない。

修正内容

- 初回クリックで必ず回答判定すること。
- 回答後は選択肢を固定すること。
- 「▶ 次へ」を押すまで選択肢を変更しないこと。
- st.rerun() により選択肢を再生成しないこと。
- 初回問題のみ発生する原因を特定し修正すること。

---

### ② 正解効果音修正

現在、

- 正解時の効果音が再生されない。

修正内容

- 正解時に必ずピンポン♪を1回だけ再生すること。
- Web Audio API を使用すること。
- 回答時のみ再生すること。
- 「▶ 次へ」では再生しないこと。
- ブラウザ(Console)エラーも確認すること。
